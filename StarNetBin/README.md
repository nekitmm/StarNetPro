# Local runtime dependencies

Runtime dependencies are not included in the source distribution.

Place the following components from a StarNet2 v2.1.0 ARM64 Torch package that you are authorized to use in this directory:

- `starnet2`
- `StarNet2_weights.pt`
- `lib/` containing the required dynamic libraries

This project targets the interface in the supplied 2023 engine. Compatibility with current releases has not been established.

Official downloads: https://starnetastro.com/cli-tools/starnet/

Before distributing an application containing these components, verify their redistribution terms and include the original licenses and third-party notices.
